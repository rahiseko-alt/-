## 比較の前提（必読）

- 参考は 72dpi の撮影画像（照明むら・JPEG のにじみ・紙の反り）。写真・切り抜き人物はプレースホルダ、文字はすべてダミーのため mismatch_ratio は下がりきらない
- **補正画像（prep）は真のページより 約 5〜7% 拡大されて見える**。理由は 3 つで、4 点の射影補正（ref:prep）では取り除けない:
  1. 天と地が撮影範囲の外にはみ出している（外周帯 10mm のうち天 約 5mm・地 約 7mm が写っていない）。prep の四隅の比率は 0〜1 に制限されるため、上下の辺は画像の端で止めるしかなく、補正画像は縦に 約 4.5% 引き伸ばされる
  2. ノド側が強く縮んで写っている（円形写真の横 / 縦がページ中央で 0.95、ノド寄りで 0.88）。さらにノド 約 9.5mm は綴じに隠れて見えない。prep は左辺（小口）とノドの谷線を両端にするので、ページ中央の要素は横に 約 7% 引き伸ばされ、5〜10mm ノド側へずれる
  3. 紙の反りによる縦のせん断（水平な線が上半分で右上がり 約 2.5°、地ではほぼ水平）
- このため、ページは prep ではなく「真の幾何」に直した推定値で組んだ（外周帯が四辺とも 10mm、円形写真が正円、パネルの横線が水平になるように、縦 6.09px/mm・天の切れ 48px・せん断と横方向の区分線形の補正を撮影画像に当てた比較用の画像を作業ディレクトリ（/tmp）で作り、そこから mm を実測）。
  公式の比較（npm run compare）の side-by-side / overlay / diff には、この拡大による系統的なずれ（上端で 約 5mm 上、下端で 約 7mm 下、中央の要素で 5〜10mm 右）が必ず出る。位置の判定は真の幾何の比較画像との重ね合わせと、要素ごとの外接矩形の実測（mm）で行い、公式の比較は構造（要素の有無・並び・大小関係）の確認に使った
  - 真の幾何の補正の値（再現用）: 回転後の画像で 小口 x = 41 + 3·(y/1715)、ノドの谷線 x = 1181 − 24·(y/1715)。縦 y_mm = (y_corr + 48.3) / 6.09、y_corr = y − s(y)·(x − 600)、
    s(y) は y = 0 / 80 / 150 / 250 / 785 / 1170 / 1640px で −0.095 / −0.09 / −0.068 / −0.05 / −0.040 / −0.030 / 0 を線形補間。
    横は (x − 小口)/(谷線 − 小口) = 0 / 0.762 / 0.833 / 0.966 / 0.980 / 1.0 を x_mm = 0 / 148.3 / 162.5 / 190.5 / 193.6 / 200.5 に区分線形で対応させる（200.5〜210mm は綴じに隠れて見えない）
- 判型: A4 縦（book.yaml の notes。裏表紙 page_009 の縦横比を円で補正すると 0.71）【要確認】
