# 和文組版のルール

紙面の文字はすべて Layer 3（HTML）で組みます。Chromium の組版機能と、エンジン同梱の CSS（`system/design-engine/src/assets/base.css`）・共通 CSS（`shared/layouts/typography.css`）を前提にしたルールです。

## 1. 書体

- 使える書体は `node_modules/@fontsource` から読み込む次の 2 書体だけ（オフラインで描画するため。Google Fonts などネットワーク経由の書体は使わない）

| 書体 | 読み込み済みウェイト | 主な用途 |
| --- | --- | --- |
| Noto Sans JP | 400 / 500 / 700 / 900 | 見出し・本文・数字（既定） |
| Noto Serif JP | 400 / 700 | 明朝の見出し・本文 |

- 書体は CSS 変数で指定する: `var(--font-heading)` `var(--font-body)` `var(--font-serif)` `var(--font-number)`（値は company-data/brand/fonts/fonts.yaml）
- 読み込んでいないウェイト（例: Serif の 900、Sans の 300）を指定しない。ブラウザの疑似ボールドになり品質が落ちる
- 書体を追加する場合: ライセンス（印刷物・PDF 埋め込みの可否）を確認 → `@fontsource` パッケージ等でリポジトリ内から読み込めるようにする（`system/design-engine/src/engine-assets.ts` の変更が必要）→ `fonts.yaml` を更新 → 全 BOOK を再出力して確認。人間の承認なしに書体を追加しない
- 出力 PDF に書体が埋め込まれていることを `pdffonts` で確認する（system/rules/output.md）

## 2. 単位

- 文字サイズは **pt**、行送りは倍率（`line-height: 1.75`）、配置・余白は **mm** で指定する
- px は使わない（解像度によって大きさが変わったように見えるため）

## 3. サイズと行送りの基準

`shared/layouts/typography.css` の既定値です。BOOK ごとの変更は `book.yaml` の `theme`（例: `"--fs-body": "9pt"`）で行います。

| 役割 | クラス | サイズ | 行送り | 備考 |
| --- | --- | --- | --- | --- |
| 大見出し（表紙・扉） | `.t-display` | 40pt 前後 | 1.2 | palt、900 |
| ページタイトル | `.t-h1` | 24pt 前後 | 1.3 | palt、700 |
| 中見出し | `.t-h2` | 16pt 前後 | 1.4 | palt、700 |
| 小見出し | `.t-h3` | 12pt 前後 | 1.5 | palt、700 |
| リード文 | `.t-lead` | 10.5〜12pt | 1.7〜1.9 | 500 |
| 本文 | `.t-body` | 9〜10pt | 1.7〜1.85 | ベタ組み（palt なし） |
| キャプション | `.t-caption` | 7〜8pt | 1.5〜1.7 | |
| 注記・出典 | `.t-note` | 6.5pt 以上 | 1.5 | 最小サイズ |

### 最小サイズ（印刷）

- 読ませる文字は **6.5pt 未満にしない**（注記・出典・法定表示を含む）
- 白抜き文字（濃い面・写真の上の白い文字）は **7pt 以上**。12pt 未満の白抜き文字はウェイト 500 以上。明朝の細い横線はつぶれやすいので白抜きの小さい文字に明朝を使わない
- この節の最小サイズと、文字を安全領域の内側に置くこと（system/rules/page-layers.md）は `npm run render` が描画結果で確かめる（通常は警告、`--release` ではエラー）。対象は白に近い色（RGB がすべて 230 以上）の文字を白抜きとして扱い、字の大きさは CSS の拡大縮小を含めた実寸で測る。読ませない装飾文字（裁ち落とす大きな英字など）だけは `data-print-qa="ignore"` を付けて対象外にできる
- 写真・生成背景の上の文字は、Layer 2 のパネル（`.panel`）や面で可読性を確保する
- 罫線は 0.1mm（約 0.3pt）以上
- QR コードは一辺 15mm 以上（system/rules/output.md）

上記は本リポジトリの社内基準です。最終的な最小サイズ・罫線の太さは印刷会社の入稿規定に従う【要確認: 印刷会社の入稿規定】。

## 4. 文字詰め（palt）

- 見出し・キャッチコピー・ラベルは `font-feature-settings: 'palt' 1`（プロポーショナル詰め）。base.css が `h1`〜`h6` と `.heading` に既定で適用する
- 本文はベタ組み（palt を使わない）。本文に palt が継承される場合は `.no-palt` で戻す
- 見出しの字間は `letter-spacing` で 0〜0.08em の範囲で調整する。1 文字ずつの手詰め（`<span>` ごとの letter-spacing）は見出しの最終調整に限る
- 約物（「」（）、。）の詰め: 見出しは `palt` で約物が半角幅になり、行頭の始め括弧も詰まる。base.css は見出しに `text-spacing-trim: trim-start`（行頭の始め括弧・隣り合う約物を詰める）も指定する。`trim-both` は Chromium 141 では未対応（無視される）ので使わない

## 5. 改行と禁則

- 禁則は `line-break: strict`（base.css で全ページに適用）。行頭に「、。」）」ー ぁぃぅ」などが来ない
- 見出しは文節で改行する（`word-break: auto-phrase`、base.css が見出しに適用。`<html lang="ja">` が前提）。本文以外で文節改行したい要素には `.phrase`
- 見出しの改行位置を固定したい場合はデータに改行を入れて `{{nl2br ...}}` で出す。HTML に `<br>` を直書きするのはページ固有の見出しに限る
- 2〜4 行の見出しは `.balance`（行長をそろえる）、本文の最終行が 1〜2 文字になる場合は `.pretty`
- 数字と単位、短い固有名詞は `.nowrap` で分割を防ぐ
- 本文の 1 行の文字数は 15〜40 字を目安にする（段組で調整する）

## 6. 揃えと段落

- 本文は両端揃え（`text-align: justify`、base.css が `p` に適用）。Chromium は和文を文字間に均等に割り付ける。`text-justify: inter-character` は Chromium では未対応（無視される）ので指定しない
- 短い行・見出し・キャプション・表のセルは左揃え（`.ta-left`）を基本にする
- 段落の字下げ: 本文に字下げを使う場合は `text-indent: 1em` を BOOK 内で統一する。リード文・キャプションは字下げしない
- 段落間は行送り 1 行分以下（`margin-block: 0.5em` 程度）。空行（空の `<p>`）で間隔を作らない

## 7. 数字・欧文・記号

- 数字は `{{num value}}` で桁区切り（`1,234`）。大きな数字は `.t-num-xl` / `.num`（等幅・ライニング数字）
- 英数字は半角で書く（company-data にも全角英数字を入れない。`npm run validate` が company-data の文字列の値にある全角英数字を警告する。原本の表記を残すならコメントに書く）
- 単位は数字より小さく（数字の 40〜60%）、ベースラインをそろえる（`stat-card` 参照）
- 年号・日付・電話番号の表記は BOOK 内で統一する（例: 「2026年4月」「03-0000-0000」の形式）
- **Noto Sans JP / Noto Serif JP（@fontsource）にない文字は使わない**: ギリシャ文字（α β Ω など）、ローマ数字（Ⅰ〜Ⅹ・ⅰ〜ⅹ）、≒ など。
  これらは環境のシステムフォント（WenQuanYi・Liberation・Noto CJK など）で代わりに描かれ、環境ごとに字形・太さが変わる（明朝の行でもゴシックになる）。
  `npm run render` は代替描画を警告し、`--release` では失敗する。言い換える（例: 「Ⅱ期」→「2期」「II期」、「β版」→「ベータ版」、「≒」→「約」）

## 8. 縦組み

- `.vertical`（`writing-mode: vertical-rl`）を使う。縦組み中の 2〜3 桁の数字は `.tcy`（縦中横）
- 縦組みの本文は行送りを横組みより広め（1.8〜2.0）にする
- 縦組みでは約物・長音・括弧の向きが変わるため、出力後に必ず目視で確認する

## 9. チェックリスト

- [ ] 指定した書体・ウェイトが読み込み済みのものだけ（疑似ボールドがない）
- [ ] 6.5pt 未満の文字がない、白抜きは 7pt・500 以上
- [ ] 見出しは palt、本文はベタ組み
- [ ] 行頭禁則・不自然な改行（単語や数字の途中、1〜2 文字の最終行）がない
- [ ] 全角英数字が混ざっていない、数字に桁区切りがある
- [ ] 出力 PDF に Noto Sans JP / Noto Serif JP が埋め込まれている（`pdffonts` に Liberation・WenQuanYi などのシステムフォントが出ていない）
- [ ] `npm run render` に「システムフォント（…）で描画されています」の警告がない
